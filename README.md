# 박기효 · Digital & Brand Designer

설치 의존성이 없는 HTML/CSS/JavaScript 반응형 포트폴리오입니다.

## 실행

```bash
cd /workspace/my-portfolio
python3 -m http.server 3000 --bind 0.0.0.0
```

## 구성

- 신한카드 플랫폼 UI/UX 고도화·운영: 현재 참여, 1년 반(사용자 제공)
- SKT T다이렉트샵 USIM 관련 고도화: 2개월(사용자 제공)
- LG전자 LGE.COM·오픈마켓 운영 디자인과 배너 가이드 개선
- 과화경 로컬 브랜드·창업 기획
- DOSIM.RECORD YouTube 및 TikTok 관련 콘텐츠 경험
- 의료 웹·마케팅·인쇄 디자인

첨부 포트폴리오와 사업계획서·발표자료를 참고했습니다. 경력 날짜는 원본 기재 기준입니다. 신한카드와 SKT의 커버는 소개용 그래픽이며 실제 서비스 화면이 아닙니다. 창업 매출·생산 목표는 실적으로 기재하지 않았습니다. YouTube 영상 34개는 사업계획서 작성 시점의 기록입니다. TikTok 계정과 지표는 확인 전이므로 추가하지 않았습니다. 원본 PDF 전체와 개인 전화번호는 사이트에 포함하지 않았습니다.

assets/에는 PDF에서 추출한 프로젝트 이미지만 있습니다. 과화경 브랜드·패키지 이미지는 원문에 AI 생성 콘셉트로 표시되어 있습니다. UI/UX 두 사례의 공개 가능한 전후 화면과 구체적 담당 범위, 검증 자료는 후속 보완 대상입니다.

## 검증

`node --check app.js` 및 HTML/CSS/JS/이미지 HTTP 응답 확인. 임시 jsdom 검증에서 6개 프로젝트 상세 열기·닫기, 필터 2/4/6, 한영 왕복 전환, 이메일, 이미지 파일, 앵커 연결을 확인했습니다. jsdom은 /tmp의 검증 도구이며 앱 의존성이 아닙니다.

실제 브라우저는 미설치 상태이며 Chromium 다운로드가 네트워크 정책(403 Domain forbidden)에 막혔습니다. 실제 레이아웃, 모바일, Escape 동작은 브라우저 검증 전입니다. Google Fonts는 선택 사항이며 접속 실패 시 시스템 글꼴로 표시됩니다. 언어 전환은 메인 소개와 공통 문구에 적용되며 프로젝트 상세와 경력은 한국어입니다.

## 단일 파일 미리보기 수정

`index.html`은 CSS·JavaScript·이미지를 내장한 독립 실행 파일입니다. 상대 경로를 해석하지 못하는 미리보기에서도 리소스 누락을 방지합니다. 수정 시 `index.template.html`, `style.css`, `app.js`, `assets/`를 편집한 다음 `node build.mjs`로 다시 생성하세요. 외부 글꼴 요청은 제거했습니다.

후속 검증: npm 배포 Chromium으로 실제 브라우저 검증을 완료했습니다. 파일 직접 열기에서 CSS 적용, 모든 본문 이미지 표시, 분야 필터, 대화상자 열기와 Escape 닫기, 언어 전환, 390px 모바일 가로 넘침 없음 및 JS 오류 없음을 확인했습니다. 앞선 브라우저 미검증 기록은 이 검증으로 갱신됩니다.
